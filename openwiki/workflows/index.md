# Files

- [Multi-Reviewer Consolidation](consolidation.md) - How multiple reviewers' independent annotation trees are aligned by optimal entry matching (align.ts + maxWeightAssignment, similarity metrics), compared field by field through the stored alignment, and reconciled into a single consolidated tree — covering the useConsolidationAlignment scheduler and its consolidationSync gate, growing/freezing/widening the tree, readiness checks, inter-rater statistics, batch unanimous adoption, and the disagreement/export surface.
- [Git Integration](git-integration.md) - The git workflow end to end — clone-to-import, the commit/pull/push/branch-switch panel, merge-branch, the field-level three-way merge at the heart of conflict resolution, the changes parser, the security gates, concurrent revision reads, the gitStore state machine, and the Electron main-process IPC plumbing that owns the only path to git.
- [AI-Assisted Annotation](llm-annotation.md) - How a reviewer invokes an LLM to pre-fill annotation fields from one paper or a whole batch — the provider abstraction, the four run modes (prompt, agent with judge, classify with System One, re-check), budgeting and retry, the aiStore batch loop with review and apply, and the security invariant that an API key never lives in the renderer.
- [PDF Viewer and Marks](pdf-viewing.md) - The PdfViewer component (react-pdf/pdf.js), zoom/navigation/search, text-selection capture for field-grabbing, internal-link hover previews, PDF marks (highlights/comments with undoable mutations), field-linking marks to annotation fields, mark export (burning marks into real PDF annotations in the Rust shell), reading-position persistence, the slr-file:// serving contract, and PDF metadata/text extraction.
- [Screening Mode](screening.md) - The screening workflow — a fast Include/Exclude decision per paper before annotation begins — covering the derived two-node schema, the tri-state status read, PRISMA-style counts, cross-field validation, the screening UI panels, the on-disk screening-* filename prefix, the screening highlights carried into the next project, and importing a screening project into an annotation project.
